# Known Limitations & Intentional Tradeoffs

This document details deliberate scope boundaries, intentional engineering tradeoffs, and future scaling milestones for the Nadi-9 translation system.

---

## 1. Intentional Tradeoffs (Time & Scope Prioritization)

### In-Memory DAG vs. Distributed Graph DB
- **Current State:** The dependency graph (`DependencyReplanner`) runs in-memory using Python dictionaries and sets.
- **Rationale:** For an episodic run (10–100 subtitles), an in-memory graph executes in microseconds and eliminates infrastructure overhead (like Docker, Redis, or Neo4j).
- **Future Scale:** For 5,000 episodes and 40 dialects, the DAG will be ported to an embedded DuckDB or Redis Graph store with persistent cache invalidation.

### Rule-Based Heuristic Parser vs. Neural Dependency Tree
- **Current State:** The morphology checks in `HypothesisEngine` and `MultiPhaseVerifier` use regex token matching and suffix pattern checks (`-ina`, `-va`, `na-`).
- **Rationale:** In a low-resource fictional dialect where no off-the-shelf spaCy or Stanza model exists, deterministic morphological rules provide 100% auditable verification without hallucination.
- **Future Scale:** Fine-tune a lightweight small language model (e.g. Qwen-2.5-Coder-1.5B or modern BERT variant) specifically trained as a token-level grammar tagger on validated Nadi-9 sentences.

### Subtitle Timing Adjustments (Warning vs. Auto-Retiming)
- **Current State:** When characters-per-second (CPS) exceeds the readability threshold (> 20 CPS), the system flags the issue and docks the confidence score, escalating to `HUMAN_REVIEW`.
- **Rationale:** Automatically compressing or trimming subtitle durations without audio waveform feedback risks desynchronizing actors' spoken cadence. Editorial human oversight is preferred for pacing.
- **Future Scale:** Integrate an automatic forced-alignment tool (e.g. WhisperX or Montreal Forced Aligner) to propose re-timed subtitle boundaries.

## 2. Decisions Intentionally Kept with Humans

1. **Sacred / Taboo Vocabulary Ingestion:** Terms with religious or communal significance are never autogenerated by LLM extrapolation.
2. **Kinship Reconciliation Nuances:** Shifting between intimate (`da-bhai`) and formal (`bhai-raj` / `vad-bhai`) address during character reconciliation arcs requires creative director signoff.
3. **Quarantine Overrides:** Releasing an item flagged by the security sanitizer requires administrative approval.
